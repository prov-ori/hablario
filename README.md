# Hablario

Интерактивный прототип курса мексиканского испанского для русскоязычных взрослых. В текущей версии 17 уроков и четыре учебные проверки по навыкам.

## Запуск

Открыть курс онлайн: [Hablario](https://prov-ori.github.io/hablario/).

Регистрация, синхронизация между устройствами, серверная проверка ответов и записи для аудирования описаны в [руководстве по установке](SETUP.md).

Установите Node.js 24.4 или новее. Из папки проекта выполните:

```sh
npm run dev
```

GitHub Pages публикует сборку из корня ветки `main`. После изменений запустите `npm run build -- --pages` и закоммитьте обновлённые HTML, CSS и JavaScript-файлы в корне вместе с исходниками.

Откройте http://127.0.0.1:4173. Для другого порта задайте переменную окружения `PORT`. Для статического хостинга выполните `npm run build` и используйте содержимое `dist/`. Внешние npm-пакеты и ключи доступа не требуются.

`npm run check` собирает приложение и запускает проверки учебных данных, оценки ответов, календаря повторений и переходов между уроками. Сборка удаляет аннотации TypeScript средствами Node. Для отдельной проверки типов с Deno используйте `deno check src/app.ts`.

## Курс

| Уровень | Текущий материал | Цель и связанные шкалы CEFR |
| --- | --- | --- |
| Pre-A1 | Знакомство, первый день на занятии | Узнать знакомое имя и простую инструкцию, представиться. Общий языковой диапазон, понимание простых указаний, устное взаимодействие. |
| A1 | О себе, время, кафе, маршрут, распорядок, семья, жильё, покупки | Найти нужное время или место в коротком сообщении, получить базовую услугу и ответить простыми фразами. Чтение для ориентации, понимание объявлений и инструкций, получение товаров и услуг. |
| A2 | Поездка, объявление и изменение плана, встреча | Понять короткое объявление, описать события и передоговориться о доставке. Понимание объявлений и инструкций, творческое письмо, получение товаров и услуг. |
| B1 | Накладка со встречей, разговор с соседями | Понять причины и условия, связно изложить события, обсудить знакомую проблему. Понимание разговора между другими людьми, развёрнутый монолог, целенаправленное сотрудничество. |
| B2 | Общественный транспорт, гибридная работа | Выделить оговорки в нескольких позициях, обосновать решение и подобрать рабочий регистр. Чтение для поиска информации и аргументов, дискуссия, отчёты и эссе. |

Вводный блок готов для прохождения. A1 — базовый маршрут, которому ещё нужны упражнения на числа и дополнительная разговорная практика. A2–B2 содержат пилотные уроки. Полноценному B2 нужны более длинные тексты и аудио, разнообразные жанры, взаимодействие с собеседником и проверка на выборке заданий. Диагностика для выбора стартового уровня пока отсутствует.

Сценарии, диалоги и задания написаны для проекта. Основа сопоставления целей и критериев — главы 3 и 5 [CEFR Companion Volume, Совет Европы](https://rm.coe.int/cefr-companion-volume-with-new-descriptors-2020/16809ea0d4). Для контекста мексиканской лексики использован [Diccionario del español de México, El Colegio de México](https://dem.colmex.mx/Diccionario).

Проверку нужно завершить перед переходом к следующему уровню. Экран различает автоматически проверенные ответы, ответы с транскриптом и пропуски. Старые результаты продолжают показывать прежний способ оценки. Раздел грамматики содержит самостоятельные занятия A1–B2.

## Прогресс, повторение и аудио

- Гостевой прогресс сохраняется в браузере. В аккаунте прогресс синхронизируется через Supabase.
- Новые карточки доступны в день завершения урока. «Не вспомнил» ставит повторение на завтра. «С трудом» сохраняет интервал, минимум один день. «Легко» удваивает его, минимум два дня. Даты рассчитываются по календарю устройства.
- Приложение воспроизводит добавленные MP3. Для остальных материалов доступна озвучка браузера и транскрипт аудирования.
- После настройки Gemini учащийся может получить автоматическую проверку открытого ответа. Устный ответ можно записать или загрузить файлом.
